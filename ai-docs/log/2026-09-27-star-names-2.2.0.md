# 2026-09-27: star names added as 2.2.0

Mark asked for a random star name generator, ideally with "every known star", without doubling the package size (2.1.0 on nuget.org is 911 KB).

## Decisions

- **Scope of "every known star".** Gaia DR3 alone has about 1.8 billion sources, and Tycho-2 (2.5 million) IDs are not contiguous, so neither fits. Chosen instead: every IAU proper name (640), every Bayer/Flamsteed designation in the Yale Bright Star Catalogue (3,076, which is every naked-eye star), and every Henry Draper (HD 1 to 225300, contiguous, stored as a constant) and Hipparcos (118,218, stored as the 2,198 missing numbers below HIP 120416) designation. Result: 343,518 catalogue stars for 15 KB.
- **Sources are primary, not HYG.** The HYG database would have been one download but is CC BY-SA 4.0, which would put share-alike data inside an MIT package. Used the IAU WGSN list (CC BY, credited in the README), VizieR V/50 (BSC5) and VizieR I/239 (Hipparcos) instead.
- **IAU list location.** Mamajek's `IAU-CSN.txt` at pas.rochester.edu stopped at 2022-04-04 (455 names). The live list is the HTML table at https://exopla.net/star-names/modern-iau-star-names/ (640 names on 2026-09-27); the build script parses rows with 10+ cells and drops the header row (the page also has a calendar widget table).
- **One designation per BSC star.** A star with a Bayer letter is listed by it, not also by its Flamsteed number; designations equal to an IAU name are dropped. BSC rows without an HD number are skipped (novae, 47 Tuc). Components use Unicode superscripts (`Alpha¹ Centauri`), so there is no plain `Alpha Centauri`.
- **API.** New `IStarNameGenerator` rather than extending existing interfaces (adding interface members breaks implementers). `GenerateRandomStarName` draws from proper + designations (3,716), not from the catalogue, so output is recognisable; the catalogue is its own method. Version 2.2.0, additive; package validation baseline stays 2.0.1.

## Verified commands

```
python tools/StarLists/build_star_lists.py --cache <dir>   # 640 / 3,076 / 2,199 lines; downloads cached in <dir>
dotnet build -c Release                                     # 0 warnings
dotnet test --no-build -c Release                           # 146/146 on net10.0 and net48
dotnet format --no-restore --verify-no-changes
dotnet pack RandomNameGeneratorLibrary --no-build -c Release -o artifacts   # 939,687 bytes, 2.1.0 local build was 896,990
```

README example rows came from a .NET 10 file-based app (`dotnet run sample.cs` with `#:project <path to the csproj>`) using `new Random(20260924)`.

## Gotchas

- On Windows, Python printing Greek or accented names to the console fails with cp1252 `UnicodeEncodeError`; run with `PYTHONIOENCODING=utf-8`.
